# Smart Todo

หน้า HTML ตัวอย่างรายการงาน Smart Todo มีรายการ `Read slides` และปุ่ม `Done`

## องค์ประกอบ HTML

- `<main>` ใช้ครอบเนื้อหาหลักของหน้า
- `<h1>` แสดงหัวข้อหลัก “Smart Todo”
- `<ul>` ใช้จัดกลุ่มรายการงาน
- `<li>` แสดงรายการ “Read slides”
- `<button type="button">` สร้างปุ่ม “Done” โดยปุ่มนี้ยังไม่มีการทำงานเมื่อคลิก เพราะโจทย์กำหนดให้มีปุ่มเท่านั้น

## วิธีเปิดไฟล์

เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์ โดยดับเบิลคลิกไฟล์ หรือคลิกขวาแล้วเลือกเว็บเบราว์เซอร์

โปรเจกต์นี้ใช้ HTML โดยไม่เพิ่ม library และไม่ใช้ backend
