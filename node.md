
# Todo List

## 1. Project Overview
A simple Todo List application built with HTML, CSS, and JavaScript.

## 2. Project Structure

- `index.html` - Defines the HTML structure.
- `style.css` - Styles the Todo List interface.
- `script.js` - Handles Todo List functionality.
- `note.md` - Documents the project.

## 3. Features

- Add a new todo item.
- Mark a todo item as completed.
- Delete a todo item.
- Display a message when there are no todo items.

## 4. How It Works

### Add Todo
The user enters a task in the input field and clicks the Add button.
JavaScript adds the task to the `todos` array.

### Complete Todo
The user checks the checkbox to mark a task as completed.
The `completed` property is updated.

### Delete Todo
The user clicks the Delete button to remove a task from the list.

### Render Todos
The `renderTodos()` function updates the displayed todo list.

## 5. Technologies

- HTML
- CSS
- JavaScript

## 6. Data Storage

Todo items are stored in a JavaScript array named `todos`.
The data is stored in memory only and is lost when the page is refreshed.

## 7. How to Run

1. Open `index.html` in a web browser.
2. Enter a task in the input field.
3. Click Add to create a task.
4. Use the checkbox to mark a task as completed.
5. Click Delete to remove a task.
